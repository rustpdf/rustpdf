# @rustpdf/linux-x64-gnu

Prebuilt `rust-pdf` native library for **linux-x64-gnu**. This is an internal,
platform-specific artifact: it is pulled in automatically as an
`optionalDependency` of [`rustpdf`](https://www.npmjs.com/package/rustpdf) when
your platform matches. **Do not depend on it directly** — install `rustpdf`.

See [rustpdf.dev](https://rustpdf.dev).
