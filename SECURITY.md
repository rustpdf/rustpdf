# Security policy

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on
[rustpdf/rustpdf](https://github.com/rustpdf/rustpdf/security/advisories/new).

Include a description, affected versions/bindings and, if possible, a
reproducing PDF or snippet. You will get an acknowledgement within a few days;
fixes ship in the next patch release of every binding.

Only the latest released version is supported.
